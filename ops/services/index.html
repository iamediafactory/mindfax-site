How to read this catalog

Three levels of complexity. One rule that never changes.

Complexity is about how much wiring, logic and judgment an automation needs — not about how valuable it is. A simple daily alert can save a client relationship; an advanced orchestration can quietly run half your ops. Use the levels to size the effort, then pick the plan by how many you want running and how fast you want new ones built.

LEVEL 1 · SIMPLE

Do one thing, reliably

A single trigger and a few steps across one or two tools. Set it once, it runs forever with monitoring on top.

e.g. a scheduled dashboard refresh, or a Slack alert when a metric drops.
LEVEL 2 · STANDARD

Move work across tools

Several integrations with branching logic — parse, decide, route, write. This is where most agency time actually goes.

e.g. a lead enriched and routed into the CRM, or an invoice drafted for approval.
LEVEL 3 · ADVANCED

Run a whole process

Multiple agents, generated drafts, exception handling and a human decision point. It operates a process, not a step.

e.g. contract-to-kickoff onboarding, or the monitoring layer over every other agent.
